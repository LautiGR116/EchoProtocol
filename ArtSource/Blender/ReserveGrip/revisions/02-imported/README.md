# ReserveGrip — original static first-person hand

`exports/EP_ReserveGrip.fbx` contains three original meshes only: ReserveRightHand, ReserveJacketSleeve and ReserveThumbNail. The source is `EchoReserveGrip.blend`; `build_reserve_grip.py` rebuilds it. No armature, animation, lights, collider, battery copy or recorded joint state is exported. Materials FIG_Skin, FIG_Jacket and FIG_Stitch match the original adult project's values; RG_Nail is an original muted nail surface. No external model, image, texture, font or generation service was used.

All meshes share the battery-bottom origin (0,0,0). The handle contact is source(0,0,.201), matching ReserveUnit's unchanged handleX[-.047,+.047]/radius.010. The source sleeve exits toward -X/-Y. With the common corrected FBX import and the 180-degree carried placement, this exits through the Player's lower-right edge. Axis/pivot/skin/wrist/sleeve values are in manifest.json; FBX uses -Z/+Y.

`previews/carried-frame.png` simulates the proposed Unity camera-local pack position(.26,-.39,.55), uniform scale1.15, corrected source(X,Z,-Y), UnityEuler(8,170,-8) and a vertical60-degree FOV at1280x720. The centre remains unobstructed. Other previews inspect the complete assembled asset and grip. `carried-raking.png` uses low oblique warm illumination in the same carried pose to reveal concave shading defects; it remains a Blender preview, not the final Unity screenshot. ReserveUnit's FBX is imported only in the transient render scene **after** this source blend is saved. It is neither edited nor exported/copied into this asset. The original pack hash is recorded in the manifest. Studio exposure/material response is not a Unity lighting result.

Final independent Blender reimport: PASS,7,688triangles; finite geometry/UV/materials, matching bounds/anchors/pivots; one closed skin surface; no armature/animation/pack mesh; sampled skin minimum radius11.349mm around the10mm handle, with zero samples more than0.5mm inside it. Nail is in contact with skin (nearest19µm, farthest4.269mm), with no detached floating nail. Report: roundtrip-checks.json. Validator reuses the project's RecoveryOffice numeric-validation core and adds connected-surface, grip-cylinder, nail-contact and asset-content checks.

Visual review supports the small matte first-person corner representation. Anatomy remains stylized, consistent with the existing adult; this is not a photoreal close-up hero hand. In-game material mapping, near-plane/wall clipping, exact framing across aspect ratios, shadows, IgnoreRaycast configuration and human visual approval remain integration/playtest work. It must stay attached to the actual Player's carried object; it introduces no Echo hand/load recording channel.

Rebuild in Blender5.2 background with build_reserve_grip.py; once exports are stable, run validate_reserve_grip.py. Both operate entirely outside Assets. Rejected early previews are retained under previews/rejected-01 only as source-iteration history.
