# Mobiliario de servicio para SE2

Geometría original del proyecto, creada en Blender sin fuentes externas. El
estuche ocupa 1×1×1.12m, con tapa, rejillas, tornillos, asas enrasadas y pies de
goma. La mesa ocupa .82×.42×.868m, con tubos, bandeja y estante. Sustituyen los
volúmenes provisionales del estado clínico y comparten su contacto físico estable
con el sillón y la consola domésticos. No tienen motor, emisión ni interacción.

`build_service_furniture.py` reproduce exports, archivo editable y manifest con
SHA256. Total11404 triángulos fuente. Reutilizan los materiales originales PP
de PressurePlant. Eje fuente X ancho / −Y frente / Z arriba; conservar rotación
importada y reflejar X del root una vez, luego aplicar yaw mundial.

Integrados como candidato en Walkthrough; las cámaras del recorrido seleccionan
su acabado. Creación objetiva, sin aprobación humana de arte o efecto emocional.
